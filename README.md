🚗 سیستم مدیریت بیمه‌نامه

یک برنامه‌ی دسکتاپی برای ثبت، مدیریت، و کنترل بیمه‌نامه‌ها
که با زبان Python و رابط گرافیکی TK توسعه داده شده است. این پروژه 
با ساختاری مرتب و ماژولار طراحی شده تا هر بخش از برنامه به‌صورت مستقل قابل تغییر و توسعه باشد.

✨ امکانات
ثبت بیمه‌نامه: ثبت اطلاعات بیمه‌نامه و جلوگیری از ورود شماره بیمه‌نامه‌ی تکراری.
مبلغ الحاقیه: افزودن و مدیریت مبلغ الحاقیه برای بیمه‌نامه‌های موجود.
ابطال بیمه‌نامه: ابطال و حذف بیمه‌نامه با استفاده از شماره بیمه‌نامه.
لیست بیمه‌نامه‌ها: مشاهده‌ی تمام بیمه‌نامه‌های ثبت‌شده و اطلاعات آن‌ها.
جلوگیری از شماره‌ی تکراری: شماره هر بیمه‌نامه فقط یک‌بار قابل ثبت است.
پیام‌های اختصاصی: برای هر عملیات، پیام‌موفقیت یا خطای مربوط به همان بخش نمایش داده می‌شود.
ذخیره‌سازی دائمی اطلاعات: اطلاعات در فایل JSON ذخیره
می‌شوند و با اجرای مجدد برنامه، اطلاعات قبلی به‌صورت خودکار بازیابی می‌شوند.
ادامه‌ی کار پس از اجرای مجدد: اطلاعات ثبت‌شده 
از بین نمی‌روند و می‌توان مدیریت بیمه‌نامه‌ها را از همان نقطه ادامه داد.

🧩 ساختار پروژه

ساختار پروژه به‌صورت ماژولار و مرتب طراحی شده است؛ هر دکمه، قابلیت یا بخش 
اصلی برنامه فایل مربوط به خودش را دارد. به همین دلیل، تغییر یا
توسعه‌ی یک قسمت نیازی به دستکاری کل پروژه ندارد.
