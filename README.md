🚗 سیستم مدیریت بیمه‌نامه

یک برنامه‌ی دسکتاپی برای ثبت و مدیریت بیمه‌نامه‌ها که با زبان Python و رابط گرافیکی Tkinter طراحی شده است.

این پروژه با ساختاری مرتب، ماژولار و قابل توسعه نوشته شده و هر بخش از برنامه فایل مربوط به خودش را دارد.

✨ امکانات
📝 ثبت بیمه‌نامه

امکان ثبت اطلاعات بیمه‌نامه در سیستم.

شماره‌ی هر بیمه‌نامه بررسی می‌شود و در صورت وجود شماره‌ی تکراری، از ثبت مجدد آن جلوگیری خواهد شد.

💰 مبلغ الحاقیه

امکان اضافه کردن مبلغ الحاقیه به بیمه‌نامه‌های ثبت‌شده.

❌ ابطال بیمه‌نامه

امکان ابطال بیمه‌نامه با وارد کردن شماره‌ی آن.

📋 لیست بیمه‌نامه‌ها

نمایش تمام بیمه‌نامه‌های ثبت‌شده به همراه اطلاعات آن‌ها.

🔔 پیام‌های اختصاصی

بعد از انجام هر عملیات، پیام مناسب همان عملیات نمایش داده می‌شود؛ مانند پیام موفقیت، خطا یا هشدار.

💾 ذخیره‌سازی اطلاعات

تمام اطلاعات بیمه‌نامه‌ها در یک فایل JSON ذخیره می‌شوند.

بنابراین با بستن و اجرای مجدد برنامه، اطلاعات قبلی از بین نمی‌روند و می‌توان ادامه‌ی کار را با همان اطلاعات انجام داد.

🛠️ تکنولوژی‌های استفاده‌شده
🐍 Python
🖥️ Tkinter — طراحی رابط گرافیکی برنامه
🖼️ PIL / Pillow — مدیریت و نمایش تصاویر
📄 JSON — ذخیره و بازیابی اطلاعات
📁 ساختار پروژه

ساختار پروژه به صورت ماژولار طراحی شده است.

هر بخش اصلی برنامه فایل مخصوص به خودش را دارد؛ بنابراین در صورت نیاز می‌توان یک قسمت را تغییر داد بدون اینکه لازم باشد کل پروژه تغییر کند.

insurance-app/
│
├── main_window.py
│
├── insurance_registration_window.py
│
├── additional_amount_window.py
│
├── insurance_policy_cancellation_window.py
│
├── list_of_insurance_policies.py
│
├── storage.py
│
├── bg.png
│
└── insurance_data.json

📌 توضیح فایل‌ها
فایل	کاربرد
main_window.py	پنجره‌ی اصلی برنامه
insurance_registration_window.py	ثبت بیمه‌نامه
additional_amount_window.py	مدیریت مبلغ الحاقیه
insurance_policy_cancellation_window.py	ابطال بیمه‌نامه
list_of_insurance_policies.py	نمایش لیست بیمه‌نامه‌ها
storage.py	مدیریت ذخیره و بازیابی اطلاعات
bg.png	تصویر مورد استفاده در رابط گرافیکی
insurance_data.json	فایل ذخیره‌ی اطلاعات بیمه‌نامه‌ها
⚙️ ویژگی‌های فنی
جلوگیری از ثبت شماره بیمه‌نامه‌ی تکراری
ذخیره‌ی دائمی اطلاعات در فایل JSON
بازیابی خودکار اطلاعات هنگام اجرای مجدد برنامه
استفاده از پنجره‌های جداگانه برای بخش‌های مختلف
نمایش پیام مناسب برای هر عملیات
ساختار کدنویسی ماژولار و قابل توسعه
جداسازی بخش‌های مختلف برنامه در فایل‌های مستقل
▶️ اجرای برنامه

ابتدا Python را روی سیستم نصب کنید.

سپس در صورت نیاز کتابخانه‌ی Pillow را نصب کنید:

pip install Pillow


برای اجرای برنامه:

python main_window.py

🎯 هدف پروژه

هدف این پروژه ایجاد یک سیستم ساده و کاربردی برای مدیریت بیمه‌نامه‌ها است.

ساختار پروژه به شکلی طراحی شده که علاوه بر استفاده‌ی راحت، امکان تغییر، نگهداری و توسعه‌ی بخش‌های مختلف برنامه نیز به آسانی وجود داشته باشد.
